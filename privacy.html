HermesOS Privacy Policy

Last updated: 29 September 2026

HermesOS is a personal assistant used only by its owner, Thabo Pali. It is not offered to anyone else, and the only Google account it accesses is the owner's own.

What it accesses

With the owner's consent, HermesOS reads the owner's Google Calendar events (titles, times, locations and descriptions) to include the day's schedule in personal briefings.

How the data is used

  • Calendar data is used only to prepare briefings and reminders for the owner.
  • To write a briefing, event details are sent to the AI model service the assistant uses for that request, and the resulting briefing is delivered to the owner's own private chat channels.
  • The Google access token is stored only on the owner's own computer.
  • The data is never sold, shared with third parties for their own use, or used for advertising.

Google API Services

HermesOS's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from Google Account → Third-party access, after which HermesOS can no longer read calendar data.
